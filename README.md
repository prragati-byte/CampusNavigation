# Campus Map Navigation System 

An interactive web-based navigation system for Graphic Era University campus built using vanilla JavaScript and Leaflet.js.

## Features
-  Find shortest path between 30+ campus locations
-  Alternative path suggestion when primary route is unavailable
-  Real GPS coordinates for all buildings, hostels, cafes and gates
-  Live map powered by OpenStreetMap

## Tech Stack
- HTML, CSS, JavaScript
- Leaflet.js (map rendering)
- Dijkstra's Algorithm (pathfinding)
- OpenStreetMap (map tiles)

## How to Use
1. Clone the repo
2. Open index.html in your browser
3. Select source and destination
4. Click "Find Paths"
